# Personal Portfolio Website

## About the Project
This is a personal portfolio website created as a Web Development project. It introduces me, my skills, my projects, and provides a contact section.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Personal introduction
- About Me section
- Skills section
- Projects section
- Contact form
- Dark mode toggle
- Responsive layout

## Files
- `index.html` – Website structure
- `style.css` – Website styling and design
- `script.js` – Website functionality

## How to Run
Download the project files and open `index.html` in any web browser.
